# Student Management System

## Project Overview

The Student Management System is a simple menu-driven Python mini-project designed to manage student records. 
It allows users to add students, view all student records, search students by roll number and calculate average marks.

## Features

1. Add Student : Enter the student's name, roll number, and marks in desired no. of subjects.
2. View All Students :  Display the details of all students.
3. Search Student by Roll Number :  Find a student using their roll number.
4. Calculate Average Marks : Calculate the average marks of a particular student.
5. Save Records: Store student details in a text file (students.txt) so that records remain available after restarting the program.
5. Exit : Close the program.

## Concepts Used

The Student Management System is developed using basic Python programming concepts.

1. Variables and Data Types: Used to store student names, roll numbers and marks.
2. Lists: Used to store multiple student records.
3. Dictionaries: Used to organise each student's information.
4. Functions: Used to divide the program into smaller and reusable sections.
5. Loops: Used to display the menu repeatedly and process student records.
6. Conditional Statements: Used to perform operations based on the user's choice.
7. File Handling: Used to save student records in a text file and retrieve them when the program starts.
8. Exception Handling: Used to handle the situation when the data file does not exist.

The project provides a simple way to add, view and search student records and calculate average marks.

## How to Run the Project

Step 1: Install Python 3 on your computer.
Step 2: Download or clone this repository.
Step 3: Open the project folder in VS Code or any Python editor.
Step 4: Run the following command in the terminal:
python student_management.py
Step 5: Select an option from the menu to use the system.
